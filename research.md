## Profile

I am Justin Kin Jun Hew. My work focuses on computational methods for fluid and plasma systems,
with emphasis on robust numerical operators, turbulence-related modeling, and scientific computing
tooling that supports reproducible analysis.

## Current Themes

- High-order numerical methods and SBP-based operators
- CFD and turbulence workflows in Python and scientific notebooks
- Data analysis pipelines for simulation-driven research

## Selected Repositories

- [pysbp-operators](https://github.com/justinh2002/pysbp-operators): Python implementation of SBP operators.
- [mhd_data_analysis](https://github.com/justinh2002/mhd_data_analysis): Analysis tools for MHD research datasets.
- [num_methods_pack](https://github.com/justinh2002/num_methods_pack): Numerical method implementations across PDE families.
- [NIF_data_analysis](https://github.com/justinh2002/NIF_data_analysis): Data analysis scripts for NIF-related research.
- [Foam_analysis_codes](https://github.com/justinh2002/Foam_analysis_codes): OpenFOAM post-processing and diagnostics.

I am interested in collaborations on scientific computing, numerical algorithms, and
